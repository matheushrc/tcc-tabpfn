\chapter{CONSIDERAÇÕES FINAIS}
\label{chap:consideracoes}
O presente trabalho teve início com o estudo na literatura para analisar os trabalhos propostos para geração de consultas de forma automática para o GraphQL. Após realizada análise na literatura, verificou-se que pouco se existe para geração de consultas de forma aleatória para o GraphQL, viabilizando a proposta do presente trabalho que é a geração de consultas válidas de forma aleatória utilizando os testes baseados em propriedade com a linguagem de programação funcional Haskell.

Ademais, este trabalho pretende contribuir na construção de consultas de teste para a tecnologia GraphQL, gerando-as automaticamente de forma aleatória e válidas, desta forma auxiliando a comunidade de desenvolvedores, e cooperando na construção de softwares mais confiáveis e de maior qualidade.
