\begin{resumo}
O GraphQL é uma linguagem de consulta de API desenvolvida pelo Facebook que é atualmente open source. Sua principal característica está em disponibilizar somente as informações solicitadas para um cliente de API, desse modo ela gera economia de recursos de rede e maior flexibilidade na comunicação entre cliente e API. Entretanto, poucos são os utilitários para automatizar testes de APIs GraphQL. Um ponto importante para se gerar casos de testes é a criação de consultas válidas, porém, esta tarefa pode consumir bastante tempo dos desenvolvedores, além de não atingir todos os casos de testes possíveis. Visando ajudar os desenvolvedores de APIs GraphQL, o presente trabalho tem como intuito a geração de consultas de forma automática baseadas no esquema da API GraphQL, gerando consultas válidas para a realização de testes, evitando trabalho humano dispensável e produzindo ampla quantidade de consultas. Como ferramenta para geração das consultas baseadas em esquema, será utilizada a linguagem de programação funcional Haskell, bem como testes baseados em propriedades.
\end{resumo}
