\begin{abstract}
GraphQL is an API query language developed by Facebook that is currently open source. Its main feature is to make only the requested information available to an API client, thus saving network resources and providing greater flexibility in the communication between the client and the API. However, there are few utilities to automate testing of GraphQL APIs. An important point for generating test cases is the creation of valid queries, however, this task can consume a lot of time for developers, in addition to not reaching all possible test cases. Aiming to help developers of GraphQL APIs, this work aims to automatically generate queries based on the GraphQL API schema, generating valid queries for testing, avoiding unnecessary human work and producing a large number of queries. As a tool for generating schema-based queries, the Haskell functional programming language will be used, as well as property-based tests.
\end{abstract}
