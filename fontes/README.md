# Fontes para consulta

Esta pasta reúne os oito estudos selecionados em `docs/artigos.md`. Sete estão em `artigo.md`, extraídos do HTML original com o MCP do Playwright em 6 ou 9 de outubro de 2026, sem tradução ou resumo. Costa et al. estão em `artigo.pdf`, pois a página editorial oferece o texto completo nesse formato. A data de extração não é a data de publicação. PDFs redundantes foram removidos conforme a preferência do autor pelo HTML.

Os títulos ficam no front matter; o corpo preserva autores, texto, citações, figuras, tabelas e referências. Os links usam URLs completas; as imagens exigem conexão. Tabelas simples usam Markdown; tabelas com células mescladas conservam HTML simplificado e organizado por linhas e células. As fórmulas usam LaTeX, sem MathML dentro dos delimitadores matemáticos. Autores, siglas, listas e referências têm formatação contínua, e controles de navegação foram removidos. Confira os elementos na fonte original antes de transcrever dados para o TCC.

Em Kutzke, os botões de tabelas e figuras foram abertos pelo Playwright. Os cinco CSVs são exportações das tabelas publicadas, e não uma cópia dos registros brutos de espectroscopia e geoquímica. A procedência dos arquivos está documentada em `hiperespectral-predicao-geoquimica/extras/README.md`. Os arquivos de fundamentação teórica não foram alterados nesta obtenção das fontes.

Para novas fontes, use uma pasta com nome curto relacionado ao assunto. Notícias, documentos institucionais e legislação podem ser guardados, respectivamente, em `noticias/`, `documentos-institucionais/` e `legislacao/` dentro de `fontes/`, quando forem adicionados. As pastas anteriores do projeto permanecem em seus locais atuais.
