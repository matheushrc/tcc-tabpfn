# Fontes para consulta

Cada artigo tem uma pasta em `artigos/`, com seu texto em `artigo.md`. As cópias foram extraídas das páginas originais usando o MCP do Playwright em 6 de outubro de 2026, sem tradução ou resumo. A data de extração não é a data de publicação.

| Pasta em `artigos/` | Fonte original | Formato |
| --- | --- | --- |
| `tabpfn-espectroscopia-solo/` | [From field-scale to large-scale spectral libraries: Tabular foundation models in soil spectroscopy](https://arxiv.org/html/2608.00608v1) | Markdown, versão v1; fórmulas em LaTeX |
| `geoquimica-rejeitos-witwatersrand/` | [Deriving big geochemical data from high-resolution remote sensing data via machine learning: Application to a tailing storage facility in the Witwatersrand goldfields](https://www.sciencedirect.com/science/article/pii/S2666544123000059) | Markdown; fórmulas em MathML |

Os arquivos preservam os títulos, o texto, as citações e as referências exibidas nas páginas. Os links de figuras e referências usam URLs completas; as imagens exigem conexão. Tabelas com células mescladas e fórmulas podem ter apresentação diferente no leitor de Markdown. Confira esses elementos na fonte original antes de transcrever dados para o TCC.

Para novas fontes, use uma pasta com nome curto relacionado ao assunto. Notícias, documentos institucionais e legislação podem ser guardados, respectivamente, em `noticias/`, `documentos-institucionais/` e `legislacao/` dentro de `fontes/`, quando forem adicionados. As pastas anteriores do projeto permanecem em seus locais atuais.
